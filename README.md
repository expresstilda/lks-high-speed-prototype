# ЛифтКомфортСервис — прототип

Версия 19 от 30 октября 2026 года. Кликабельный прототип предложения высокоскоростных лифтов.

- [Прототип](index.html)
- [Документ с текстами](docs/landing-copy.html)
Формы и кнопки Telegram и MAX демонстрационные: данные и файлы не отправляются и не сохраняются. Изображения оборудования — из материалов производителей; изображения объектов — из публичного портфолио ЛКС. Характеристики относятся к указанным сериям и исполнениям.

GitHub Pages: корень ветки main; статические файлы без Jekyll.

Подбор без ТЗ — демонстрационный квиз из пяти шагов. Ответы живут только в текущем окне, передача на сервер и расчёт стоимости не выполняются.
