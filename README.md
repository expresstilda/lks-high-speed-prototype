# ЛифтКомфортСервис — прототип

Версия 29 от 2 ноября 2026 года. Кликабельный прототип предложения высокоскоростных лифтов.

- [Прототип](index.html)
- [Документ с текстами](docs/landing-copy.html)
Формы и кнопки Telegram и MAX демонстрационные: данные и файлы не отправляются и не сохраняются. Изображения оборудования, зданий и объектов заменены подписанными плейсхолдерами. Сканы документов и иконки интерфейса сохранены. Характеристики относятся к указанным сериям и исполнениям.

GitHub Pages: корень ветки main; статические файлы без Jekyll.

Подбор без ТЗ — демонстрационный квиз из пяти шагов. Ответы живут только в текущем окне, передача на сервер и расчёт стоимости не выполняются.

Юридический интерфейс: обязательные согласия у четырёх форм, отдельные макеты политики и согласия, уведомление и настройки cookie. Домен и рабочая инфраструктура не определены; реальная отправка данных и аналитика не подключены.
